# Rubble Rush

**철거 로봇이 폐시설을 부수고, 잔해를 케이블로 둘러싸 끌고, 구멍에 밀어넣는 3D 모바일 액션 게임.**

구멍은 삼킨 만큼 커지고, 커질수록 더 큰 것을 삼킨다.

> Unity 6 · URP Mobile · C# · 1인 개발 · NCAI 최종 프로젝트

---

## 한 바퀴

```
          부순다            둘러싼다              밀어넣는다
   건물에 다가가 두드린다 → 케이블로 잔해를 감싼다 → 구멍 위를 지나간다
            ↑                                          │
            └──────────── 구멍이 커진다 ←───────────────┘
```

세 동작이 서로 다른 조작이고 순서가 있다. 게임 안에 **가르치는 튜토리얼**이 들어 있다 —
이동 → 부수기 → 케이블 → 구멍 삼키기를 일곱 단계로 차례대로 시킨다.

## 조작

| | 키보드 | 터치 |
|---|---|---|
| 이동 | `W` `A` `S` `D` / 방향키 | 왼쪽 아래 조이스틱 |
| 부수기 | 건물 근처에서 `E` | 건물 옆에 뜨는 단추 |
| 두드리기 | 아무 키 연타 / 클릭 | 화면 두드리기 |
| 케이블 | `Q` | 오른쪽 아래 `케이블` |
| 대쉬 | `Shift` | 오른쪽 아래 `대쉬` |

## 해 보기

WebGL 빌드는 Brotli 로 압축되어 있어, 서버가 `Content-Encoding: br` 를
같이 보내야 한다. `python -m http.server` 로는 안 된다.

```bash
python Tools/serve_webgl.py Builds/WebGL/Rubble_Rush_v0.1.0 8123
```

브라우저에서 `http://127.0.0.1:8123/` 를 연다.

## 만든 방법

| 영역 | 도구 |
|---|---|
| 엔진 | Unity 6 (6000.3.18f1) · URP Mobile 프리셋 |
| 입력 | New Input System (터치 + 키보드 동시) |
| 3D 에셋 | VARCO 3D 생성 → Blender(bpy) 정리 → FBX |
| 2D 에셋 | VARCO 이미지 생성 → 파이썬으로 분할·키잉 |
| 오디오 | VARCO Sound |
| 밸런스 | `Tools/balance/*.csv` ↔ 유니티 에디터 메뉴로 왕복 |

**UI 는 전부 IMGUI 다.** Canvas 를 쓰지 않는다 — 씬 와이어링은 사람이 손으로 하는
작업이라, 코드가 소유할 수 있는 쪽을 골랐다.

**구역은 씬이 아니라 데이터다.** `ZoneData` ScriptableObject 하나에 건물 배치가 들어 있고
런타임에 생성된다. 그래서 레벨 구성까지 코드와 CSV 가 소유한다.

## 에셋에 대하여

이 저장소에는 **유료·라이선스 에셋이 들어 있지 않다.** Odin Inspector, DOTween,
Cartoon FX, 구매한 효과음 묶음 등은 `.gitignore` 로 제외되어 있다.
클론한 뒤 유니티가 그 참조를 못 찾는다고 해도 정상이다.

커밋에 들어간 이미지·효과음은 VARCO 로 이 프로젝트를 위해 생성한 것이다.
글꼴은 배달의민족 도현체·을지로체(상업적 이용 허용)다.

## 상태

알파. WebGL 빌드가 돌고, 튜토리얼 한 판(3분)을 끝까지 플레이할 수 있다.

아직 없는 것: 튜토리얼 외 스테이지, 안드로이드 서명 빌드, 사운드 전환 옵션.
