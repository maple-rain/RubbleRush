# PART A — 확정된 설계

## 1. 컨셉

**[합의]** 철거 로봇이 폐시설을 해체한다. 잔해를 케이블로 둘러싸 구멍에 밀어넣는다.

톤은 산업(철거 현장). **[미결]** 판타지(돌 골렘 + 고대 유적)로 바꿔도 메커닉은 동일하며 외형 스킨만 교체하면 된다. 아직 확정하지 않았다.

### 설계 제약 — 왜 이 형태인가 **[확정]**

| 제약 | 결과 |
|---|---|
| 생성 AI는 유기체를 잘 못 만든다 | 등장 대상이 전부 하드서피스 (기계·구조물·배관·탱크) |
| 스켈레탈 애니메이션을 만들 시간이 없다 | 플레이어는 무한궤도 차량. 이동은 트랜스폼, 궤도는 텍스처 스크롤 |
| 전투 시스템을 넣을 시간이 없다 | **적이 없다.** 위협은 전부 플레이어가 부순 결과에서 나온다 |
| 모바일 터치 | 조준 없음. 조이스틱 하나 + 버튼 하나 |

### 핵심 딜레마 **[확정]**

두 동사가 같은 질문을 반복한다 — **크게 갈 것인가, 빠르게 갈 것인가.**
둘 다 "크게"가 무방비 시간을 늘린다.

```
부순다 → 잔해가 흩어진다 → 케이블로 둘러싼다 → 끌고 간다 → 구멍에 투입 → 구멍이 커진다 ↺
```

**[합의]** 구멍이 커질수록 더 큰 것을 삼킬 수 있고, 후반에는 부수지 않고 통째로 밀어넣는다.
성장을 몇 단계로 나눌지는 **정해지지 않았다** (→ PART B §8).

## 3. 입력 **[확정]**

| 영역 | 입력 | 동작 |
|---|---|---|
| 왼쪽 절반 | 가상 조이스틱 | 이동. 견인량에 비례해 감속 |

WebGL 키보드 매핑: `WASD` 이동, `Space` 홀드/연타.

## 4. 파괴 **[확정]**

### 4.1 두 선택지

이것이 기획자가 정한 파괴 대상 구성이다. **두 종류다.**

| 대상 | 시간 | 보상 | 위험 |
|---|---|---|---|
| **벽면** | 짧다 | 적다 | 낮다 |
| **기둥** | 길다 | 많다 | 붕괴 — 깔릴 수 있다 |

**[합의]** 잔해 분포도 갈린다 — 벽면은 발밑에 떨어져 작은 고리로 즉시 회수되고, 기둥은 붕괴하며 넓게 흩어져 큰 고리가 필요하다. 파괴 선택이 수집 시간까지 결정한다.

> 구체적인 수치(시간·잔해 수·산란 반경)는 **정해지지 않았다.** PART B §11의 값은 AI 창작이다.

### 4.2 3단계 상태 **[합의]**

```
Intact  ──>  Damaged  ──>  Rubble
```

메시를 **교체**한다. 물리 파괴가 아니다. 교체는 프레임 하나에 끝나고, 먼지 파티클·화면 흔들림·파괴음이 그 프레임을 덮는다. 비용이 일정해서 모바일에서 돈다.

`Rubble` 상태의 오브젝트는 맵에 남는다 — 들어올 때와 나갈 때의 스카이라인이 달라야 한다.

### 4.3 하이라이트 파괴 (연타) **[확정]**

```
홀드 (균열 누적) → 연타 5~7초 → 최후의 일격 (단발 터치)
```

- 연타는 **하이라이트에만** 붙는다. 상시 유지하지 않는다 — 손이 아프고 판단이 사라진다
- 연타 구간은 **길어도 5~7초**
- 연타 이후 **터치로 최후의 일격**을 가한다

**[제안·미승인]** 최후의 일격에 판단을 넣는 방식(약점 터치 / 타이밍 창 / 지연 보상)은 AI 제안이며 미결이다.

**[확정]** 캐릭터의 생김새와 세계관이 "왜 연타해야 하는가"에 답해야 한다.
**[합의]** 유압 브레이커는 원리 자체가 반복 타격이므로 이 조건을 만족한다.

### 4.4 연출 요구사항 **[확정]**

연타 중에 **화면이 흔들리고, 대상이 부서지고, 그 변화가 눈에 보여야 한다.**

**[합의]** 두 층으로 나눈다.

| 층 | 내용 |
|---|---|
| 순간 | 균열 확산 · 파편 낙하 · 대상 흔들림 · 화면 흔들림과 음 피치가 진행도에 비례 상승 |
| 누적 | 부순 것이 맵에 남는다. 들어올 때와 나갈 때의 스카이라인이 다르다 |

## 5. 수집 **[확정]**

### 5.1 케이블

버튼을 누른 채 이동하면 **선이 남고, 선이 다 이어지면 그 안의 내용물을 끌어서 옮길 수 있다.**

**[합의]** 세부 동작:

| 단계 | 동작 |
|---|---|
| 전개 | 버튼을 누른 채 이동 → 궤적 포인트 기록 |
| 폐합 | 새 포인트가 기존 궤적과 교차하면 고리 성립 |
| 포획 | 고리 내부 잔해가 케이블에 딸려온다 |
| 견인 | 끌면서 이동. 총 무게에 비례해 감속 |
| 추가 | 견인 중에 다시 둘러싸면 합쳐진다 |

**[합의]** 쌓인 잔해 위로는 케이블이 지나가지 못한다. 이 한 줄로 잔해 누적이 별도 페널티가 아니라 수집 메커닉의 일부가 된다.

**[합의]** 판정은 바닥 평면 기준 2D. 층이 나뉘면 층별 독립 처리. 폐합 판정은 닫히는 순간 1회만 실행한다.

### 5.2 구멍

**[확정]** 구멍을 유지한다. 잔해를 끌고 가서 넣는다.

**[합의]**
- 구멍 크기가 진행도다. 넣을수록 커지고, 커지면 더 큰 것을 삼킨다
- 구역당 2~3개. "어느 구멍으로 갈 것인가"가 경로 판단이 된다
- 근처에 오면 빨려든다 — 정확히 올릴 필요 없다
- 플레이어는 빠지지 않는다. 층간 낙하도 없다

> 성장 공식과 잠금 단계는 **정해지지 않았다.** PART B §9 참조.

# PART B — AI 제안 (승인받지 않음)

> **아래는 전부 AI가 임의로 만든 것이다.** 기획자가 정한 것이 아니며,
> 채택·수정·폐기 모두 기획자 판단이다. 참고용으로만 남긴다.

## 9. 구조물 세분화 제안 — **미승인**

기획자는 **기둥 / 벽면 2종**을 정했다. AI가 이를 **6종 5티어**로 확장했다.

| 대상 | AI가 붙인 티어 |
|---|---|
| 판자 · 드럼통 | 0 |
| 벽면 · 배관 | 1 |
| 기둥 | 2 |
| 철골 프레임 | 3 |
| 건물 코어 | 4 |

**이 확장에는 근거가 없다.** 5단계여야 할 이유도, 6종이어야 할 이유도 없다. 2단계일 수도 3단계일 수도 있다.

그리고 이 확장이 **실제로 문제를 만들었다** — 티어가 많아지자 높은 티어가 낮은 티어를 완전히 무의미하게 만드는 효율 폭주가 생겼고, AI는 그것을 면적 성장 공식으로 풀었다. **2종이었으면 존재하지 않았을 문제를 만들고 푼 것이다.**

**결정 필요**: 구조물을 몇 종, 몇 단계로 갈 것인가.

## 10. 구멍 성장 공식 제안 — **미승인**

```
반경 = sqrt( (π · r0² + k × 누적단위) / π )
```

면적 기반. 선형 성장을 쓰면 해금이 성장을 가속하고 그게 다시 해금을 앞당기는 자기가속이 걸린다는 것이 시뮬레이션에서 나왔다 — 단, **그 폭주 자체가 §9의 5티어 구조에서 나온 것**이므로 구조가 바뀌면 이 공식도 무의미해질 수 있다.

**결정 필요**: 성장을 공식으로 둘 것인가, 단계표로 둘 것인가, 아니면 다르게 할 것인가.

## 11. 붕괴 반응 예산 제안 — **미승인**

Project.K의 반응 예산 체계를 AI가 이 게임에 이식한 것이다. 기획자가 요청한 적 없다.

```
반응 예산 = 붕괴 경고 시간 − 시스템 총 지연 0.1s − 탈출 소요 시간
탈출 소요 = 낙하 반경 / 이동 속도(견인량)
```

착안점은 **견인량이 반응 예산을 직접 깎는다**는 것 — 많이 끌수록 느려지고, 느릴수록 탈출 소요가 길어져 등급이 내려간다. "많이 모으면 위험해진다"를 정량화한다.

**결정 필요**: 이 체계를 쓸 것인가. 쓴다면 등급 경계를 어떻게 잡을 것인가.

아래 숫자는 **AI가 만든 것이며 기획자가 검토한 적 없다.** 시뮬레이션을 돌리기 위한 입력이었을 뿐이다.

### 이 시뮬레이션이 검증하지 **않은** 것

> 검증 도구 역시 기획의 산물이며, 도구 자체를 교차 검증하지 않으면 통과(PASS)를 맹신하게 된다.
> — Project.K 포스트모템

여기서는 도구보다 **입력이 문제**다. 구조도 수치도 AI 창작이므로, 이 PASS는 "AI가 만든 세계가 스스로 모순되지 않는다"는 뜻밖에 없다.

그 위에 모델 자체의 미반영 항목이 더 있다.

| 미반영 | 영향 |
|---|---|
| 이동 거리를 상수로 고정 (대상 10m · 구멍 15m) | 구조물이 줄수록 멀어지고 구멍이 커질수록 가까워진다. 후반 효율이 실제와 다르다 |
| 케이블 고리를 완전한 원으로 계산 | 볼록 껍질로 더 짧게 그릴 수 있다. 55m는 과한 값일 가능성이 크다 |
| 잔해 누적 차단을 확률 10%로 근사 | 실제 지형 차단은 배치 의존적이다 |
| 붕괴를 기댓값으로만 처리 | 연쇄 붕괴로 대량 획득하는 경우가 없다. 기둥이 과소평가되어 있다 |
